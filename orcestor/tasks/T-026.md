## Task ID: T-026
### Sarlavha: [Perf 1/6] Skeleton/bubble loading — umumiy shared komponent

**Ijrochi:** AGY

**Bog'liqlik:** Yo'q — bu seriyaning (T-026–T-031, performance/UX
optimallashtirish) birinchi taski, chunki keyingi tasklar (ayniqsa
DataTable'ni yangilaydigan T-027/T-028) shu skeleton komponentdan
foydalanishi mumkin.

**Persona/uslub (agents/skills/):**
`agents/skills/engineering/engineering-frontend-developer.md` uslubida —
performance-first va vizual jihatdan mavjud dizaynga mos UI komponenti.

**Maqsad (Goal):**
`shared/components/ui/` ichida qayta ishlatiladigan `SkeletonLoader`
komponentini yaratish (skeleton/"bubble" animatsiyali placeholder) va
uni `DataTable`ning hozirgi oddiy spinner+matn loading holati o'rniga
ulash.

**Kontekst (Context):**
- Hozir `shared/components/ui/data-table/data-table.html`da loading holati
  faqat spinner + "Yuklanmoqda..." matni (`loading-state` bloki, 25-27
  qatorlar atrofida) — skeleton/bubble animatsiya yo'q.
- Yangi komponent generic bo'lishi kerak: nechta "qator" va nechta
  "ustun" ko'rsatilishi `@Input()` orqali sozlanadigan (masalan
  `rows: number = 5`, `columns: number = 4`), shunda uni DataTable'dan
  tashqari boshqa joylarda ham (masalan card-based ro'yxatlarda) ishlatish
  mumkin bo'ladi.
- Mavjud komponent fayl strukturasi konventsiyasiga rioya qiling
  (standalone, alohida `.ts`/`.html`/`.css`, `shared/components/ui/`
  papkasida, masalan `confirm-dialog`ning fayl tuzilishiga o'xshab).

**Cheklovlar (Constraints):**
- Yangi npm dependency qo'shmang — faqat CSS animatsiya (masalan
  `@keyframes` bilan shimmer/pulse effekt) va Angular native imkoniyatlar.
- `DataTable`ning tashqi `@Input()`/`@Output()` API'siga (columns, data,
  loading, pageSize, emptyMessage, rowClick, sortChange) putur
  yetkazmang — faqat ICHKI loading holatini almashtiring, DataTable'ni
  ishlatuvchi 13+ list sahifasining birortasi ham o'zgarishi shart emas.
- Global stil fayllarini (`styles.css`) o'zgartirmang, faqat komponent
  ichidagi lokal CSS ishlating (T-013/T-017 dark/light CSS custom
  property sxemasi mavjud bo'lsa, o'sha o'zgaruvchilardan foydalaning,
  hardcoded rang yozmang).

**Ish doirasidagi fayllar (Files in scope):**
- `src/app/shared/components/ui/skeleton-loader/` (yangi papka)
- `src/app/shared/components/ui/data-table/data-table.ts`,
  `data-table.html`, `data-table.css` (faqat loading holati qismi)

**Bajarilgan deb hisoblanish mezoni (Definition of Done):**
- `SkeletonLoader` standalone komponent, `rows`/`columns` (yoki
  o'xshash) `@Input()` orqali sozlanadi, shimmer/pulse animatsiyasi bor.
- `DataTable`ning `loading-state` bloki `<app-skeleton-loader>` bilan
  almashtirilgan (yoki qo'shilgan), DataTable'ning tashqi API'si
  o'zgarmagan.
- `npm run build` va `npx tsc --noEmit` xatosiz o'tadi.
- Vizual ravishda skeleton jadval ustunlari/qatorlariga mos ko'rinadi.
