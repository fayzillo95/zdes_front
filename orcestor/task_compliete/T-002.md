## Task ID: T-002
### Sarlavha: orcestor/dispatch.py — vazifa hayot siklini boshqaruvchi Python skript

**Maqsad (Goal):**
`orcestor/dispatch.py` nomli Python skript yozish — bu skript `orcestor/tasks/ → task_pending/ → task_compliete/` oralig'ida topshiriq fayllarini ko'chirish va `orcestor/status/` ichiga vaqt belgili (timestamped) status yozuvlarini qo'shish orqali vazifa hayot siklini (task lifecycle) boshqaradi.

**Kontekst (Context):**
Bu — Claude Code (orkestrator) + AGY (sub-agent) + Fayzillo (supervayzer) fayl-asosidagi orkestratsiya tizimining amaliy (operational) qismi. To'liq arxitektura: `../ROOT.MD`, `./README.MD` (papka tuzilishi va lifecycle diagrammasi), `./requirements.MD` (qoidalar/rollar), `./prompt.md` (topshiriq shabloni), `./steps/01-intake.md` dan `./steps/06-logging.md` gacha (aniq bosqichlar tavsifi).

**Muhim: hozircha Claude Code va AGY o'rtasida to'g'ridan-to'g'ri API bog'lanish yo'q** (Gemini API key muammosi hal qilinmagan, Antigravity esa yopiq UI). Shuning uchun bu skript **faqat lokal fayl boshqaruvi** uchun — u hech qanday tashqi API'ga (Gemini, Claude va h.k.) murojaat qilmaydi, faqat fayllarni ko'chiradi/loglaydi.

**Cheklovlar (Constraints):**
- Faqat Python **standart kutubxonasi** (`argparse`, `pathlib`, `shutil`, `datetime` va h.k.) — hech qanday tashqi `pip` paketi talab qilinmasin.
- Tashqi API'larga (Gemini, Anthropic va h.k.) murojaat qilmasin — bu sof lokal fayl-boshqaruv vositasi.
- Mavjud `orcestor/prompt.md`, `orcestor/steps/`, `orcestor/requirements.MD` fayllariga tegmang, faqat ularga havola/mos ishlang.
- CLI interfeys aniq va o'z-o'zini tushuntiruvchi (`--help` orqali) bo'lsin.

**Ish doirasidagi fayllar (Files in scope):**
- Yangi fayl: `orcestor/dispatch.py`
- O'qish uchun (faqat reference): `orcestor/prompt.md`, `orcestor/steps/*.md`

**Bajarilgan deb hisoblanish mezoni (Definition of Done):**
- `python3 orcestor/dispatch.py --help` ishlaydi va quyidagi subkomandalarni ko'rsatadi:
  - `new <TASK_ID>` — `orcestor/prompt.md` shabloni asosida `orcestor/tasks/<TASK_ID>.md` bo'sh qoralamasini yaratadi
  - `send <TASK_ID>` — faylni `orcestor/tasks/` dan `orcestor/task_pending/` ga ko'chiradi
  - `complete <TASK_ID>` — faylni `orcestor/task_pending/` dan `orcestor/task_compliete/` ga ko'chiradi va `orcestor/status/<TASK_ID>.log` ga vaqt belgili yozuv qo'shadi (masalan: `2026-07-24T23:50:00 — T-002 completed`)
  - `status` — barcha topshiriqlarning joriy holatini (qaysi papkada ekanligini) ro'yxat qilib chiqaradi
- Skript hech qanday tashqi `pip install` talab qilmasdan ishlaydi.
- Fayl boshida qisqa docstring/izoh — foydalanish namunasi bilan.
- Xato holatlari (masalan mavjud bo'lmagan TASK_ID) tushunarli xabar bilan ishlov beriladi, dastur crash bo'lmaydi.

**Tavsiya etilgan Antigravity rejimi (Mode):**
Agent-driven — aniq ta'riflangan, izolyatsiyalangan (bitta yangi fayl), tashqi bog'liqliksiz vazifa.
