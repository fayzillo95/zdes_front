## Task ID: T-001
### Sarlavha: Darken dizayn tokenlarini styles.css'ga qo'shish

**Maqsad (Goal):**
`src/styles.css` dagi mavjud `@theme` va `:root[data-theme="dark"]`
tokenlariga `project_docs/design-reference.md` bo'lim 2'da ta'riflangan
yangi aksent va status ranglarini qo'shish — mavjud light tema va mavjud
tokenlarning qiymatlarini o'zgartirmasdan.

**Kontekst (Context):**
Loyiha Tailwind CSS v4 (CSS-first `@theme` konfiguratsiyasi) ishlatadi.
Tema tizimi `src/styles.css` da: `@theme` bloki (statik ranglar) +
`:root { ... }` (light, default) + `:root[data-theme="dark"] { ... }`
(dark override). To'liq dizayn spetsifikatsiyasi:
`project_docs/design-reference.md` (bo'lim 1-2, rang jadvali shu yerda).

**Cheklovlar (Constraints):**
- Mavjud tokenlarning (`--color-bg-primary`, `--color-text-primary` va
  h.k.) light variantdagi qiymatlarini o'zgartirmang.
- Faqat YANGI tokenlar qo'shiladi: `--color-chart-purple`,
  `--color-chart-pink`, `--color-chart-green`, `--color-chart-yellow`,
  `--color-chart-blue`, `--color-status-completed`,
  `--color-status-pending`, `--color-status-canceled` — qiymatlar
  `design-reference.md` bo'lim 2'dagi jadvaldan olinadi.
- `--color-status-completed` va `--color-status-canceled` uchun mavjud
  `--color-success` / `--color-danger` tokenlariga `var(...)` orqali
  havola bering (qiymatni takrorlamang).
- `:root[data-theme="dark"]` bloki uchun `design-reference.md` bo'lim 2
  "Fon" qismidagi chuqur ko'k-binafsha gradient fikrini `--color-bg-primary`
  va `--color-bg-secondary` dark qiymatlariga asos sifatida oling (butun
  sahifa background'ini `body` selectoriga gradient sifatida qo'llash
  mumkin, lekin mavjud `body` qoidasini butunlay qayta yozmang — faqat
  `background-color`/`background` xususiyatini kengaytiring).
- Boshqa hech qanday faylga tegmang (faqat `src/styles.css`).
- Yangi npm dependency qo'shmang.

**Ish doirasidagi fayllar (Files in scope):**
- `src/styles.css` (mavjud, faqat shu fayl o'zgaradi)
- `project_docs/design-reference.md` (o'qish uchun, o'zgartirilmaydi)

**Bajarilgan deb hisoblanish mezoni (Definition of Done):**
- Yuqoridagi 8 ta yangi token `@theme` yoki `:root[data-theme="dark"]`
  ichida (mos joyda) qo'shilgan.
- Mavjud light tema vizual ravishda o'zgarmagan (eski token qiymatlari
  bir xil qolgan).
- `npm run build` xatosiz o'tadi.
- Fayl boshqa hech narsa (component, routing, boshqa CSS fayllar)
  o'zgartirilmagan.

**Tavsiya etilgan Antigravity rejimi (Mode):**
Agent-driven — vazifa bitta faylga cheklangan, aniq ta'riflangan.
