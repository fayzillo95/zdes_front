## Task ID: T-017
### Sarlavha: Jadval "Amallar" ustunida hoverda `<hr>`ga o'xshash effektni tekshirish va tuzatish

**Maqsad (Goal):**
Foydalanuvchi xabar berdi: jadvallardagi "Amallar" ustunida delete
tugmasi ustiga sichqoncha olib borilganda (hover) `<hr/>`ga o'xshash
chiziq effekti hali ham ko'rinadi. Aniq sabab **vizual reproduksiyasiz
kod o'qish orqali topilmadi** — shu sabab bu task avval tekshiruv,
keyin tuzatish talab qiladi.

**Kontekst (Context):**
Tekshirilgan va inkor etilgan gipotezalar (`holiday-list.css` namunasida):
- `.btn-action`da `border: none;` mavjud, `.btn-delete:hover` faqat
  `background`/`color` o'zgartiradi, aniq `border-bottom`/`hr` qoidasi
  YO'Q.
- Global `src/styles.css`da `button`/`:focus`/`:hover` uchun umumiy
  reset/outline qoidasi topilmadi.
- Literal `<hr>` tegi hech qanday feature template'ida yo'q.
- Bitta aloqasiz topilma: `payroll-list.css`da eski `.action-buttons`/
  `.edit-btn`/`.edit-btn:hover` (hardcoded `#3b82f6`) klasslari HTML'da
  ishlatilmasa ham CSS'da qolib ketgan (o'lik kod, T-010a Amallar
  ustunini butunlay olib tashlagan payt tozalanmagan) — bu hoverdagi
  hr-effektga sabab bo'lishi DALIL BILAN ISBOTLANMAGAN, lekin baribir
  design-reference.md bo'lim 3.3'ning "eski class nomlari qolmasligi
  kerak" qoidasiga zid, shuning uchun shu task doirasida ham tozalanadi.

**Birinchi qadam — vizual reproduksiya (ijrochi frontend'ni ishga
tushirib — `npm start`, `localhost:4200` — birnechta list sahifada
"Amallar" ustunidagi delete tugmasi ustiga hover qilib, brauzer
DevTools (Elements/Computed panel) orqali aniq qaysi CSS qoida chiziqni
hosil qilayotganini aniqlaydi):**
1. Kamida 3 ta turli list sahifada (masalan `holiday-list`, `branch-list`,
   `employee-list`) hover holatini tekshiring — effekt hammasida bormi
   yoki faqat ba'zi sahifalardami, aniqlang.
2. DevTools'da hover holatini "pin" qilib (Force state: hover), Computed
   panelda `border`/`box-shadow`/`outline`/`text-decoration` qiymatlarini
   ko'ring — qaysi qoida chiziqni chiqarayotganini toping.
3. Agar sabab brauzer-default `<button>` fokus/hover chizig'i bo'lsa
   (masalan `-webkit-appearance` yoki default `outline`), `.btn-action`ga
   aniq `outline: none;` qo'shing (agar hozir yo'q bo'lsa).
4. Har qanday sabab topilsa, tuzating va **screenshot yoki DevTools
   Computed qiymati bilan** `T-017-response.md`da dalillang (shunchaki
   "tuzatdim" deb yozish YETARLI EMAS — qaysi qoida sabab bo'lganini
   aniq ko'rsating).

**Ikkinchi qadam — o'lik kod tozalash:**
`payroll-list.css`dagi ishlatilmayotgan `.action-buttons`/`.edit-btn`/
`.edit-btn:hover` qoidalarini o'chiring (HTML'da bu klasslar yo'qligini
