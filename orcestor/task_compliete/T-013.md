## Task ID: T-013
### Sarlavha: Detail sahifalarni kanonik detail-card strukturasiga o'tkazish

**Maqsad (Goal):**
`project_docs/design-reference.md` bo'lim 3.5'da tasvirlangan kanonik
detail-card strukturasini quyidagi 2 ta sahifaga qo'llash (namunaning
o'zi, `payroll-detail`, TEGILMAYDI):
- `src/app/features/employees/pages/employee-detail/employee-detail.html` + `.css`
- `src/app/features/attendance/pages/attendance-detail/attendance-detail.html` + `.css` + `.ts` (agar kerak bo'lsa, faqat template uchun ma'lumot formatlash metodlari qo'shish maqsadida)

**Kontekst (Context):**
Namuna: `src/app/features/payroll/pages/payroll-detail/payroll-detail.html`
+ `.css` (bo'lim 3.5'da to'liq keltirilgan) — `.detail-card` >
`.detail-row` > `.label` + `.value` strukturasi.

**Har biri uchun aniq ko'rsatma:**

### 1. `employee-detail.html` + `.css`
- Hozirgi `.info-card` / `<p><strong>` strukturasini
  `.detail-card`/`.detail-row`/`.label`/`.value`ga o'tkazing (mavjud
  maydonlar: FIO, Telefon, Status, Qabul qilingan sana — bittasi ham
  qo'shilmaydi/olib tashlanmaydi).
- `.edit-btn`dagi 3 ta hardcoded hex rangni token'larga almashtiring
  (`design-reference.md` bo'lim 3.1 rang xaritasidan foydalaning:
  `.btn-edit` uchun `var(--color-primary)` asosli qiymatlar).
- "Tahrirlash" tugmasi (`[routerLink]="['edit']"`) SAQLANADI, olib
  tashlanmaydi — bu mustaqil detail sahifa, list-qator emas.

### 2. `attendance-detail.html` + `.css`
- Hozirgi ingliz-tilidagi, uslubsiz stub butunlay qayta yoziladi.
- `.detail-card`/`.detail-row`/`.label`/`.value` strukturasi
  ishlatiladi, sarlavha "Davomat tafsilotlari".
- Faqat `Attendance` modelida (`src/app/core/models/attendance.ts`)
  haqiqatda mavjud maydonlar ko'rsatiladi: xodim (`employeeId`),
  sana (`date`), kirish vaqti (`checkIn`), chiqish vaqti (`checkOut`),
  ishlangan daqiqa (`workedMinutes`), kechikish (`lateMinutes`), holat
  (`status`). Sana/vaqt formatlash uchun
  `src/app/features/attendance/pages/attendance-list/attendance-list.ts`
  dagi `formatDate`/`formatTime` metodlariga o'xshash formatlash
  qo'llang (xohlasangiz xuddi shu metodlarni `attendance-detail.ts`ga
  ko'chirib yozing).
- "Loading..." matni o'rniga "Yuklanmoqda..." (yoki oddiy bo'sh holat).
- Yangi maydon/ma'lumot o'ylab topilmaydi.

**Cheklovlar (Constraints):**
- `payroll-detail`ga (namuna) hech qanday o'zgartirish kiritilmaydi.
- Ma'lumotlarni backend'dan olish logikasi (`ngOnInit`,
  `attendanceService.getById`, `employee$` observable) O'ZGARTIRILMAYDI
  — faqat template/CSS.
- Yangi npm dependency qo'shilmaydi.
