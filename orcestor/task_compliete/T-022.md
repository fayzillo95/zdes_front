## Task ID: T-022
### Sarlavha: Detail sahifalarga xatolik holati (error-state) qo'shish + attendance-detail'dagi yetishmayotgan error handler

**Maqsad (Goal):**
`project_docs/design-reference.md` bo'lim 3.6, 4-qismidagi detail-sahifa
patternini 3 ta sahifaga qo'llash: `employee-detail`, `payroll-detail`,
`attendance-detail`. `employee-detail`/`payroll-detail` hozirgi
`x$ | async as x; else loading` qolipidan aniq `subscribe()` + signal
qolipiga o'tkaziladi (async pipe xato holatini ajrata olmaydi).
`attendance-detail.ts`da `subscribe()`da **umuman `error` callback yo'q**
— xato bo'lsa hech narsa (hatto console log ham) chiqmaydi, bu alohida
bug sifatida ham tuzatiladi.

**Kontekst (Context):**
To'liq pattern (signal struktura + 3 holatli `.html` shart bloki)
`design-reference.md` bo'lim 3.6, 4-qismida keltirilgan.

**Muhim eslatma:** T-015 (agar allaqachon bajarilgan bo'lsa) shu uchala
faylning `.detail-card` fonini `var(--color-bg-primary)`ga tuzatgan —
bu taskda o'sha o'zgarish SAQLANADI, faqat `.ts`/`.html`dagi
loading/error logikasi qo'shiladi.

**Cheklovlar (Constraints):**
- `employee-detail.ts`/`payroll-detail.ts`: `x$: Observable<X>` property
  o'rniga `item = signal<X | null>(null)` + `loading`/`loadError`
  signal, `ngOnInit` orqali `subscribe()`. `.html`da `async` pipe
  o'rniga `item()`/`loading()`/`loadError()` ishlatiladi.
- `attendance-detail.ts`: mavjud `attendance` propertysi saqlanadi,
  FAQAT `loading`/`loadError` signal qo'shiladi va `subscribe()`ga
  `error` callback qo'shiladi (`this.loading.set(false);
  this.loadError.set(true); console.error(...)`).
- Ma'lumot olish manzili (`getById` chaqiruvi, `route.paramMap`/
  `route.snapshot.paramMap`) O'ZGARTIRILMAYDI — faqat subscribe
  usuli va state boshqaruvi.
- Mavjud content (detail-card/detail-row) HTML qismi o'zgarmaydi,
  faqat qaysi shart ichida ko'rsatilishi o'zgaradi.

**Ish doirasidagi fayllar:**
`src/app/features/employees/pages/employee-detail/employee-detail.ts` + `.html`,
`src/app/features/payroll/pages/payroll-detail/payroll-detail.ts` + `.html`,
`src/app/features/attendance/pages/attendance-detail/attendance-detail.ts` + `.html`
(6 ta fayl).

**Bajarilgan deb hisoblanish mezoni (DoD):**
- Uchala sahifada ham loading/xatolik/muvaffaqiyat holatlari aniq
  ajratilgan.
- `attendance-detail`da endi HTTP xatosi console'da ko'rinadi va
  foydalanuvchiga error-state ko'rsatiladi (avval sukut saqlangan).
- `npm run build` xatosiz o'tadi.

**Tavsiya etilgan rejim:** Agent-driven (struktura o'zgarishi bor, lekin
3 faylda bir xil pattern — namuna sifatida `attendance-detail.ts`ning
mavjud `subscribe()` qolipidan foydalanish mumkin).
