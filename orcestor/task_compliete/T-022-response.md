# T-022 Bajarilish jarayoni

1-qadam: Topshiriq matni va namuna API hujjatlari bilan tanishildi.
2-qadam: `payroll`, `salary-adjustments`, `settings`, `notifications` modullari va ularning model fayllari o'rganilmoqda.
3-qadam: Barcha 4 ta modul (payroll, salary-adjustments, settings, notifications) API va state ma'lumotlari tahlil qilindi va tegishli `.md` hujjatlari yaratildi.
4-qadam: Loyihadagi barcha 17 ta API hujjatlarini o'z ichiga olgan hamda State boshqaruvini umumlashtiruvchi `README.md` indeksi yaratildi.
