`project_docs/design-reference.md` bo'lim 3.6, 3-qismidagi list-sahifa
error-state patternini quyidagi 4 ta sahifaga qo'llash: `branch-list`,
`company-list`, `department-list`, `employee-list`.

**Kontekst (Context):**

`design-reference.md` bo'lim 3.6, 3-qismida. CSS klasslar (`.error-state-box`

(plain yoki `signal`) `loadError` qo'shiladi, mavjud `load*()` metodining

`console.error(...)` qo'shiladi, `.html`da mavjud bo'sh-holat blokidan
oldin yangi `.error-state-box` bloki qo'shiladi (bo'sh-holat shartiga
`!loadError` qo'shiladi).
