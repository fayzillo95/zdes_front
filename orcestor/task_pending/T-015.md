## Task ID: T-015
### Sarlavha: Detail-card hardcoded oq fonni tokenlashtirish (dark tema buzilishi)

**Maqsad (Goal):**
Foydalanuvchi xabar berdi: `http://localhost:4200/employees/<id>` sahifasi
"dizayn dabdala" (qorong'i temada oq karta + o'qilmas matn). Sabab
aniqlandi: `.detail-card` klassi 3 ta faylda ham (jumladan T-013'ning
o'zi namuna sifatida ko'rsatgan `payroll-detail.css`) `background: white;`
— hardcoded, token emas. Bularni `var(--color-bg-primary)`ga
almashtirish kerak (`.table-card`/`.form-card`da ishlatilgan konventsiya
bilan bir xil).

**Kontekst (Context):**
Tekshirilgan, aniq qator raqamlari:
- `src/app/features/payroll/pages/payroll-detail/payroll-detail.css:20`
  — `background: white;`
- `src/app/features/attendance/pages/attendance-detail/attendance-detail.css:20`
  — `background: white;`
- `src/app/features/employees/pages/employee-detail/employee-detail.css:23`
  — `background: white;` (shu faylda yana `font-family: 'Inter', system-ui,
  sans-serif;` ham qator 5'da bor — bu ham arbitrar/hardcoded, boshqa
  sahifalarda font-family override yo'q, shu qator ham OLIB TASHLANADI,
  global font ishlatiladi).
- Namuna: `src/app/features/branches/pages/branch-list/branch-list.css`dagi
  `.table-card { background: var(--color-bg-primary); ... }` konventsiyasi.

**Cheklovlar (Constraints):**
- FAQAT `background: white;` qatori `background: var(--color-bg-primary);`
  ga almashtiriladi (3 faylda). `employee-detail.css`da qo'shimcha
  `font-family` qatori (5-qator) olib tashlanadi.
- Boshqa CSS qoidalar, HTML struktura, `.ts` fayllar O'ZGARTIRILMAYDI.
- `project_docs/design-reference.md` bo'lim 3.5'ga eslatma qo'shiladi:
  "Namuna sifatida ko'rsatilgan `payroll-detail.css`dagi `.detail-card`
  foni ham T-015'da tuzatildi (avval hardcoded `white` edi) — yangi
  nusxa oluvchilar `var(--color-bg-primary)`ni ishlatishi kerak."

**Ish doirasidagi fayllar:** `payroll-detail.css`, `attendance-detail.css`,
`employee-detail.css`, `project_docs/design-reference.md` (4 ta fayl).
